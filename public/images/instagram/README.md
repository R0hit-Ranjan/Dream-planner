# Instagram Photos & Reels Assets

Place Rahul Ranjan's high-resolution Instagram photos or exported camera files directly in this directory:
`public/images/instagram/`

Supported formats: `.jpg`, `.jpeg`, `.png`, `.webp`, `.mp4`

Once placed here, you can reference them in `src/config/siteConfig.ts` or `src/components/InstagramFeed.tsx` using paths like:
`/images/instagram/photo-1.jpg`
