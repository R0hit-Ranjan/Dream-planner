## 💻 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```

### 4. Preview Production Build
```bash
npm run preview
```

## ⚙️ Configuration & Customization

All copy, services, package prices, and contact information can be updated in one place:
- **`src/config/siteConfig.ts`**: Update the phone number, email, story milestones, services, packages, and portfolio items.
- **WhatsApp Phone Number**: Set the environment variable `VITE_WHATSAPP_NUMBER` in a `.env` file (e.g. `VITE_WHATSAPP_NUMBER=919876543210`) or edit `siteConfig.ts`.
